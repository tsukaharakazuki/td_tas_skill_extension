指標の定義

  • 配信: メールは Send イベントの通数（抑止リスト分を含む）。LINEは送信リクエスト数（リトライはまとめて1）。
  • 到達率: 到達 ÷ 配信。メールは Delivery、LINEは LINE API が受け付けた数。
  • 開封率 / クリック率: 開封（クリック）があった通数 ÷ 到達。1通に何回開封しても1と数えます。
  • CTOR: クリック ÷ 開封。失敗率: メールはバウンス、LINEは API エラーの通数 ÷ 配信。
  • Bot判定を除く: Engage Studio の is_bot_event = Likely（セキュリティスキャン等による自動開封・クリックの可能性が高い）を除外します。
  • LINEの開封・クリックは配信ログに含まれないため「—」と表示します。
